\begin{abstract}
A contextual-bandit policy built on a retrained model faces a mismatch: its
statistical confidence is naturally built from the gradient features that were
fixed when each reward was collected, while its scores are computed with the
current relinearized generalized Gauss--Newton or Fisher metric, which changes
every replayed Jacobian at once.  We ask when the first can justify the second,
and we keep four objects distinct throughout: the frozen confidence metric, the
exact current metric, the symmetric positive definite operator the algorithm
actually applies, and the numerical width a solver returns.  A
Thompson--Finsler path certificate transports frozen confidence to current
curvature, a two-sided operator comparison relates that metric to the applied
operator, and a solver certificate relates exact operator widths to the widths
the action selector sees.  The resulting conditional upper-confidence-bound
theorem closes regret through frozen sequential information gain and permits
measurable approximate selection on standard-Borel action spaces.  For
differentiable squared-loss models a corrected prediction center establishes
the reference-confidence event for any predictable parameter path inside the
certified region, with no nonlinear optimizer-convergence assumption;
historical and current approximation errors stay explicit in the radius.  A
locked 29-parameter scaled-tanh audit, run as a dense controlled study rather
than a benchmark, records simultaneous float64 confidence and optimism in all
600 transport-Hessian runs with no deterministic audit failure.  The same audit
shows the negative half of the result: the analytic path certificate is
conservative by five to six orders of magnitude against the endpoint distance,
every reported numerical regret bound is vacuous relative to the deterministic
cap, and all three comparison policies attain lower sample-mean pseudo-regret at
the primary horizon.  Validity of an analytic transport certificate therefore
does not by itself deliver a useful bound or better regret, and we report the
conditions under which the theorem holds rather than a curvature advantage.
\end{abstract}
