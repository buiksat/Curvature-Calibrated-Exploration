\begin{abstract}
Retraining a contextual-bandit model changes the gradient features used to score
actions, while sequential confidence rests on features fixed when rewards were
collected.  We study when this confidence can justify scores based on current
relinearized generalized Gauss--Newton or Fisher curvature.  Our conditional
upper-confidence-bound theorem separates the frozen confidence metric, current
metric, applied operator, and numerical solver width.  It composes a
Thompson--Finsler path certificate, a two-sided operator comparison, and a solver
certificate to bound regret through frozen sequential information gain, allowing
measurable approximate selection on standard-Borel action spaces.  For
differentiable squared-loss models, a corrected prediction center establishes
reference confidence along any predictable parameter path inside the certified
region, without assuming nonlinear optimizer convergence.  Historical
approximation errors enter the radius; current errors remain additive.  A
controlled audit of a 29-parameter scaled-tanh model uses dense matrices and
Cholesky solves.  All 600 transport-Hessian runs retain simultaneous float64
confidence and optimism, with no deterministic audit failure.  However, the
analytic path certificate exceeds the endpoint distance by five to six orders
of magnitude, every reported numerical regret bound exceeds the deterministic
cap, and all three comparison policies attain lower sample-mean pseudo-regret
at the primary horizon.  The base confidence component dominates the recorded
bound decomposition.  These findings separate certificate validity from bound
tightness and policy performance; they establish no uniform regret ordering or
practical curvature advantage.
\end{abstract}
