\begin{abstract}
Contextual-bandit policies use confidence estimates to balance exploration and
reward. For nonlinear predictors, retraining can change gradient-based estimates
without adding observations, but standard sequential confidence arguments do not
automatically justify confidence bands based on recomputed gradients. We develop
confidence transport
to connect a valid reference confidence band, built from gradients fixed before
each reward, to scores based on recomputed gradients. The approach uses certified
bounds on matrix changes and numerical error. Under explicit statistical and
computational conditions, it yields an upper confidence bound policy with a regret
guarantee. The conversion has a limit: with the same history, center, radius and
bias, the certified uncertainty width cannot be smaller than the reference width.
Exact actionwise transport recovers that width; this comparison does not order
regret across policies with different adaptive histories.
A prespecified study compares four policies in three conditions using one
synthetic 29-parameter scaled-tanh model and 50 paired seeds per condition.
Hessian transport, which bounds matrix changes using prediction Hessians, has
higher mean pseudo-regret than every comparator in each condition; all nine
pointwise paired 95\% confidence intervals for regret differences exclude zero.
Transport inflation dominates its regret bounds. Both these bounds and the
reference policy's own bounds exceed a deterministic regret cap.
All policies, including an uncertified control, pass the recorded floating-point
confidence and optimism checks. These checks establish neither universal validity
nor a practical advantage. The results separate three questions for exploration
with relinearized gradients: whether confidence is conditionally valid, whether
regret bounds are informative, and whether decisions improve.
\end{abstract}
