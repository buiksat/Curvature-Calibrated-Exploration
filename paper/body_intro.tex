\section{Introduction}\label{sec:intro}

At each round, a contextual-bandit policy predicts the reward of every available
action, adds an uncertainty bonus, and chooses from the resulting scores.  For a
fixed linear representation, the same feature vectors support both the
statistical confidence argument and the widths used for action selection.  A
retrained nonlinear model breaks this identification.  The query used at round
$s$ was $\bq_s(a_s)=\nabla_\theta\mu_{\btheta_s}(x_s,a_s)$, fixed before
observing $r_s$, whereas a policy that replays the same sample at round $t$ uses
$\nabla_\theta\mu_{\btheta_t}(x_s,a_s)$.  Updating $\btheta_t$ changes every
replayed Jacobian at once, so the current relinearized Gram no longer has the
predictable rank-one recursion required by the usual self-normalized argument.

Existing neural-bandit methods avoid or absorb this mismatch in different ways.
NeuralUCB and NeuralTS accumulate gradient features when observations arrive
\citep{zhou2020neural,zhang2021neural}; NTK methods can keep the uncertainty
features at initialization \citep{kassraie2022neural}; and neural-linear methods
place exact linear uncertainty on a learned last-layer representation
\citep{riquelme2018deep}.  Fixed-reference network linearizations and post-hoc
Laplace approximations provide related predictive-uncertainty tools
\citep{maddox2021fast,daxberger2021laplace}, but they do not answer the online
question studied here: when can confidence built from collection-time features
justify scores computed with current replayed curvature?

Validity alone does not explain why a policy should use that curvature.
Transporting an existing confidence bound does not add statistical information:
on a fixed history, the construction below produces an upper width at least as
large as the direct reference width.  A loose certificate can therefore preserve
optimism while making the bonus dominate reward predictions.  We study both the
conditional guarantee and this operational limitation.  A completed controlled
study motivates the distinction: the evaluated Hessian-transport policy has
higher mean regret than each comparator in every follow-up condition, although
all policies, including an uncertified control, pass the recorded optimism
diagnostics.

Four objects must remain distinct.  The frozen Gram $\bVbar_t$ supports
sequential statistical confidence.  The exact current metric $\bV_t$ replays
past observations at the current parameter.  The algorithm applies an SPD
operator $\Calg_t$, which may approximate $\bV_t$.  Finally, a solver returns
the numerical upper width $\hat s_t(a)$ used in the score.  The analysis
certifies the chain
\[
 \begin{aligned}
  \bVbar_t\ (\text{frozen confidence})
    &\ \xrightarrow{\text{path certificate}}\ \bV_t\ (\text{current metric}),\\
  \bV_t\ (\text{current metric})
    &\ \xrightarrow{\text{operator comparison}}\ \Calg_t\ (\text{applied operator}),\\
  \Calg_t\ (\text{applied operator})
    &\ \xrightarrow{\text{solver certificate}}\ \hat s_t(a)\ (\text{score width}).
 \end{aligned}
\]
Each arrow has a separate obligation.  A Thompson--Finsler path length controls
the first arrow through a two-sided exponential Loewner sandwich
\citep{thompson1963certain,nussbaum1994finsler}.  A second two-sided comparison
accounts for replacing $\bV_t$ by $\Calg_t$.  Solver certification then provides
an upper-valid width for every scored action and a sharpness factor only for the
action actually played.  The lower operator comparison is needed to return the
played width to the frozen sequential potential.  A one-sided upper comparison
alone does not satisfy the hypotheses of the closed bound studied here.

For squared loss, the main statistical construction is a corrected prediction
center.  It combines the current nonlinear prediction with a ridge correction
computed from collection-time features.  This identity holds for any predictable
parameter path inside the certified region, so the confidence proof does not
require the nonlinear optimizer to converge.  Historical Taylor and
misspecification errors enter the radius through an explicit energy, while
current errors enter additively.  These terms remain genuine costs: persistent
misspecification can make the guarantee linear or vacuous.

One decision round now has a concrete order.  Before the reward is observed, the
learner forms the current query and corrected center, constructs or receives
$\Calg_t$, certifies transport and operator distortion, computes one upper-valid
width map over the score domain, and selects an action.  Only then does it observe
the reward and update the frozen statistics and model.  The theory permits
matrix-free CG to apply a fixed SPD operator through curvature--vector products,
provided its width satisfies the solver certificate.  This separates solve
approximation from operator approximation; it is not the implementation audited
here.  Nor does a matrix-free solve make total policy memory $O(d)$, because the
corrected center still needs frozen-feature access or a separately certified
representation.

\paragraph{Guarantee and scope.}
The transported-UCB theorem composes reference confidence, metric transport,
operator distortion, solver error, and approximate score maximization, then
closes regret through frozen information gain
(\Cref{thm:transported-ucb}).  Factor-path and prediction-Hessian certificates
make the metric comparison operational without a small-drift premise
(\Cref{lem:factor-spd-path,cor:hessian-path-new}), and the corrected-center
specialization yields finite-dimensional and near-linear rates without an
optimizer certificate
(\Cref{cor:corrected-center-new,cor:finite-d-rate-new,%
cor:global-near-linear-new}).  Thompson geometry, the sandwich-to-width
comparison, and the UCB determinant-potential argument are established tools.
Our analysis organizes their obligations for current replayed curvature,
including the distinction between all-action upper validity and selected-action
sharpness of the same numerical score.

\paragraph{A limitation and a sharper specialization.}
We make explicit the elementary same-history width comparison and its equality
case: exact actionwise transport reproduces the reference width
(\Cref{prop:reference-width-floor}).  An exact endpoint Thompson-distance factor
is uniform and need not attain that equality for every action.  Neither
comparison orders the realized regret of policies that collect different data.
For the scaled-tanh specialization, fixed feature directions permit a direct
relative-weight sandwich, with a horizon-independent uniform bound and a tighter
category-weight construction (\Cref{cor:tanh-relative-weights}).  These
comparisons avoid the ridge-only Hessian envelope without claiming a general
result for rotating neural gradients or a new confidence event.

\paragraph{Controlled evidence.}
The prespecified stronger-drift follow-up uses a 29-parameter scaled-tanh model
with dense matrices and direct Cholesky solves in float64
(\Cref{sec:transport-followup}); the original near-linear audit is retained
separately in \Cref{sec:transport-instantiation}.  The follow-up evaluates four policies in three conditions, with 50 paired seeds per
condition.  All nine pointwise paired intervals favor the comparators over
Hessian transport.  The original grid's bound decomposition is base-dominated;
the follow-up's is path-dominated, and the frozen policy's own-trajectory bound
is also vacuous.  Changing the smoothness parameter changes the reward task, so
these are separate conditions, not a controlled causal intervention on drift.
Exploratory analyses of the retained histories measure width-dominated selection
and audit the relative-weight certificate.  Alternative scores on those same
histories are diagnostic recommendations, not alternative adaptive-policy runs.
The evidence supports a limitation of this implementation; it establishes
neither universal policy dominance nor end-to-end scalability.  Approximate
operators and CG remain theoretical interfaces and are not evaluated here.
