\section{Introduction}\label{sec:intro}

An upper confidence bound (UCB) policy adds an uncertainty bonus to a predicted
reward. For a nonlinear predictor, retraining can change historical gradients
without collecting new observations. The usual sequential confidence argument
uses features fixed before their rewards; replayed gradients can instead
depend on those rewards. We ask how a valid collection-time confidence band
can support scores computed from current relinearized curvature.

\paragraph{Contributions.}
First, for squared loss, a frozen ridge correction supplies a confidence band
around the corrected center along any predictable parameter path in a
certified region, using supplied Taylor and misspecification bounds and
requiring no optimizer convergence (\Cref{cor:corrected-center-new}).
Second, on a fixed history with the same center, radius and bias, certified
transported widths cannot improve on the reference width; an exact actionwise
correction recovers it (\Cref{prop:reference-width-floor}). The symmetric
exponential width factors are sharp (Section~\ref{sec:logarithmic-transport}).
Third, scaled tanh admits a relative-weight endpoint certificate because its
gradient directions stay fixed (\Cref{cor:tanh-relative-weights}).
A log-Lipschitz bound on the link derivative gives a further certificate
controlled by index movement, and when $W\ge cT$ the uniform endpoint factor
is $1+O(1/(cT))$, so the endpoint-transported bound has the frozen bound's form
(\Cref{cor:tanh-lipschitz-endpoint,cor:tanh-endpoint-regime}).
\Cref{thm:transported-ucb} connects these results: reference confidence,
metric transport, operator comparison and numerical-width certificates give
an implemented UCB score and a regret bound.

NeuralUCB and NeuralTS retain arriving gradient features
\citep{zhou2020neural,zhang2021neural}; fixed NTK references and learned
last-layer uncertainty offer other constructions
\citep{kassraie2022neural,riquelme2018deep}. Current-curvature scoring creates
the additional certificate obligations studied here. Sections
\ref{sec:abstract-transport}--\ref{sec:closed-rates-new} give the framework,
geometry, corrected center and rates; Section~\ref{sec:transport-followup}
reports the study. Proofs and supporting details are in the appendices.
