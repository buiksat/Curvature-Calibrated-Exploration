## 4. What the review rounds found

Five independent passes. Each found something its predecessors structurally could not, which is
the main lesson worth carrying forward.

| Round | Method | Found |
|---|---|---|
| 1 | Mechanical diff and count checks | Two citations silently dropped by the related-work reorganization (`mackay1992practical`, `martens2015optimizing` — the K-FAC paper) |
| 2 | Prose review against the formal blocks | The Conclusion had replaced `W = Ω(T)` with "grows with the horizon", a strictly weaker condition under which the corollary's own bound goes vacuous |
| 3 | External review | Score width described as bounding the inverse quadratic form rather than its square root; three `qquad` tokens missing their backslash |
| 4 | External review | Centering certificate described as comparing against a global minimizer rather than the frozen-feature ridge estimator; an unsupported trust-region sufficiency claim; an unmatched parenthesis in inline math |
| 5 | External review | `\|\hat\rho\| = \sqrt{F_t}` should be `\le` inside the `lem:confidence` proof; a missing fixed-tolerance qualifier on the CG budget; "improves to" for a bound that does not dominate; solves conflated with iterations |

Two defect classes are worth naming because they defeat ordinary checking:

**Prose that misdescribes an unchanged formal block.** The mathematics is byte-identical, so
every diff and hash check passes while the surrounding sentence changes what it says. Rounds 2,
3, 4 and 5 all found instances. Only reading catches these.

**Mechanical defects inside frozen mathematics.** Missing backslashes, unbalanced delimiters.
They survive because they are identical at both ends of every range examined, and
`paper/validate.py` cannot see them: its brace check counts `{}` and never `()`, and nothing
checks for bare operator names. All such defects found so far predate the rewrite.

## 6. Build requirements

The AISTATS manuscript builds with:

```bash
cd paper && latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

Expected result: exit 0, **64 pages**, zero undefined references or citations, zero
multiply-defined labels, five overfull boxes (pre-existing). Then
`python3 paper/validate.py` should report 261 labels, 184 reference targets, 37 citation keys,
zero unresolved, and PASS.

The CODE abstract builds the same way from `submissions/code_mit_2026/` and yields exactly
3 pages with zero warnings.

**Expect to install packages on a fresh machine.** The session's build host shipped only a
minimal TeX Live and was missing everything below; all were installed into `TEXMFHOME`
(`~/texmf`) without root, plus `latexmk` into `~/bin`:

```
mathtools  mhsetup  cleveref  pgfplots  cm-super
newtx  txfonts  xpatch  fontaxes  xstring  tex-gyre  microtype
```

`cm-super` is the non-obvious one: without it the document typesets all 64 pages and then dies
at font embedding with `cm-super-ts1.enc: cannot open encoding file`. `txfonts` is similarly
required by `newtxmath` and fails late with a missing `txsyb.tfm`.

Two verification gotchas that cost time and produced false alarms:

- `cp -a paper/. <builddir>` copies stale build artifacts, after which `latexmk` reports a
  phantom missing `mathtools.sty` before its own first run. Use `git archive` instead.
- Ghostscript's `txtwrite` emits real ligatures, so extracted text contains `ﬁ` (U+FB01) and
  `ﬀ` (U+FB00). An ASCII grep for "fixed" or "off" against extracted PDF text produces false
  negatives. Normalize U+FB00–FB06 before comparing.
